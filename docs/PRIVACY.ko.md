# 개인정보 안내

**Audio Focus Mixer**는 기기 내에서 동작하는 앱이에요. 계정·광고·사용자 분석 SDK·인터넷 권한을 사용하지 않아요.

## 접근하는 정보

- **설치된 앱 목록:** `QUERY_ALL_PACKAGES` 권한으로 앱 이름, 패키지 식별자, 아이콘 등을 기기에서 읽어 표시해요.
- **오디오 포커스 설정:** 사용자가 Shizuku 권한을 허용하면 선택한 앱의 `TAKE_AUDIO_FOCUS` 모드를 조회하거나 변경해요.
- **복원 기록:** 변경 전에 앱 패키지 식별자와 이전 AppOps 모드를 앱 전용 내부 저장소에 저장해요. 복원 기능에만 사용해요.

## 보관과 전송

개발자가 운영하는 서버나 광고·분석 서비스로 정보를 전송하지 않아요. 앱에 `INTERNET` 권한도 없어요.

Shizuku는 사용자가 별도로 설치하고 허용하는 서비스예요. Shizuku 자체의 동작과 정책은 이 앱의 범위를 벗어나요. 도움말 링크를 열면 브라우저 등 외부 앱을 사용할 수 있어요.

복원 기록은 복원하거나 앱을 제거할 때까지 남아요. 앱 삭제 시 기록은 사라지지만 시스템 AppOps 설정은 남을 수 있으니 **삭제 전에 복원해주세요.**

## 문의와 변경

문의는 저장소의 GitHub Issues를 이용해주세요. 개인정보 처리 방식이 달라지면 이 문서와 변경 기록에 알릴게요.
